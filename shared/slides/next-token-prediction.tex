    \NNDSorNN{A token-level task of special interest is \myalert{next-token prediction}:
    at each position,}{The recurrent lectures predicted the next value of a
    time series from its history. We now repeat this for text
    (\myalert{next-token prediction}): a sequence model (e.g., an RNN) maps
    $\vc{X}$ to $\vc{Y}\sim(T,C')$, and at each position} a vocabulary classifier
    $\vc{p}_t=\operatorname{softmax}(g(\idx{\vc{Y}}{t,:}))\sim(V)$ predicts
    the following token $z_{t+1}$.

    The targets come from the text itself, without human labels: the task is
    \myalert{self-supervised}, and a text of $T+1$ tokens gives $T$ examples:
