# Figure sources

These are the available sources for figures imported into the linear-model pilot.
They retain the original filenames from `slides-nnds-2026`. The parent directory
contains the exact PDF assets used in both baseline decks.

The `.drawio` file is editable with diagrams.net. The Python plot scripts use
NumPy and Matplotlib; read each script before regenerating its output. Figure
regeneration is optional and is not part of the PDF-equivalence experiment.
