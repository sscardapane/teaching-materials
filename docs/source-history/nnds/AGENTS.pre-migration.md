# NNDS material guidance

Read [NNDS_REFRESH.md](NNDS_REFRESH.md) for slide revisions, notation, instructor
review and visual verification. Follow any instructions in the target subdirectory.
Preserve approved source material and unrelated edits. Use `latexmk` from `latex/`
without `-pdf` (the repository selects LuaLaTeX). Notebook checks use the relevant
draft's verification script. Deployment remains an explicitly requested effect;
pushing changes under `html/` can trigger Pages, so inspect workflow paths first.
